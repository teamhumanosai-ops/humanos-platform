# Artifact Detector

## Purpose

The Artifact Detector is responsible for identifying the type of every artifact entering Human OS.

The detector runs before extraction.

## Responsibilities

- Detect file type
- Detect MIME type
- Detect URLs
- Detect repositories
- Detect source
- Validate supported formats

## Future

The detector will support:

- Documents
- Images
- Audio
- Video
- Code
- Websites
- GitHub
- Email
- Calendar
- Databases
